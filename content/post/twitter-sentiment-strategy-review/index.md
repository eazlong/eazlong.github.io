## 二、发现的漏洞与问题

### 🔴 严重问题

#### 1. 数据滞后性的表述矛盾

**位置**：第2.3节 vs 第4.2节

**问题**：2.3节说情绪是"预测信号"（拐点追踪），4.2节又说情绪"滞后于价格1-3天"

**风险**：读者可能困惑——到底该用情绪做预测还是确认？

**建议**：统一表述，明确区分"预测型信号"和"确认型信号"的使用场景

#### 2. 情绪指标计算方法缺失

**位置**：第3节

**问题**：提到了"情绪得分"和"多空比率"，但未说明具体计算公式

**风险**：读者无法复现策略，实操性大打折扣

**建议**：补充情绪得分计算公式，例如：
```
情绪得分 = (正面推文数 - 负面推文数) / 总推文数
多空比率 = 看涨推文数 / 看跌推文数
```

#### 3. 回测结果缺失关键数据

**位置**：第5节

**问题**：提到"策略在回测中表现优于基准"，但未给出具体数据

**风险**：读者无法评估策略真实效果，信任度降低

**建议**：补充回测结果表格，包括：
- 年化收益率
- 最大回撤
- 夏普比率
- 胜率

### 🟡 中等问题

#### 4. API使用限制未说明

**位置**：第2.2节

**问题**：提到使用Twitter API，但未说明免费版和付费版的限制差异

**风险**：读者可能选择错误的API层级，导致数据不足或成本超支

**建议**：补充API层级对比表格：
- Free tier: 1,500 posts/month
- Basic tier: $100/month, 10,000 posts/month  
- Pro tier: $5,000/month, 1M posts/month

#### 5. 情绪分类器准确率未提及

**位置**：第2.1节

**问题**：使用预训练模型进行情绪分类，但未说明模型准确率

**风险**：读者无法评估信号质量，可能误用噪声数据

**建议**：补充模型在加密货币领域的F1-score（建议>0.75）

#### 6. 风险管理参数缺失

**位置**：第4.3节

**问题**：提到"止损机制"，但未给出具体参数

**风险**：读者不知道如何设置合理的止损点

**建议**：补充具体参数建议：
- 单笔止损: -5%
- 组合止损: -10%
- 动态止损: ATR × 2

### 🟢 轻微问题

#### 7. 学术引用格式不一致

**位置**：全文

**问题**：部分引用有年份（如"Jiang et al., 2021"），部分没有

**建议**：统一使用 APA 格式引用

#### 8. 代码示例不完整

**位置**：第3.2节

**问题**：提到使用 Python 和 Pandas，但代码片段缺少import语句

**建议**：补充完整代码示例
